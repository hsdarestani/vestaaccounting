# Vazirmatn

Unmodified variable web font from the official [Vazirmatn v33.003 release](https://github.com/rastikerdar/vazirmatn/tree/v33.003). The accompanying OFL.txt contains the upstream SIL Open Font License. SHA-256: `4e3fa217d38fdafc1fea4414ceb58ca5e662cf0ab5fa735a8c8c20e8b42cad92`.

The Worker uploader includes this asset as `Vazirmatn.woff2` (a binary data module) alongside `entry.mjs`, `worker.mjs`, `ui.mjs` and `theme.mjs`. The PostgreSQL runtime reads the same checked-in asset from disk. A privately licensed IRANYekan file remains optional and takes precedence if configured.
